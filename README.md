# yoooteacher

分析原课件、了解学生当前基础，再沿老师的教学路线生成个性化可视化学习材料。

这是一个 Agent Skill 项目，首版面向数学、计算机类 PDF，主要产物是可离线打开、可打印的 HTML 学习课件。它规定来源核对、短对话诊断、解释深度、图像复用与成品验证；不包含自动识别所有课件的转换器、学生评分系统或网站后台。

## 先看成品

同一份三页自制二分查找课件，对应两种预设学生基础：

- [展开基础与证明](examples/binary-search/foundation.html)：补充有序性、闭区间与不变量，展开建立、保持和终止。
- [简短回顾与条件核对](examples/binary-search/fluent.html)：保留同样的原页序、公式和原图，缩短基础解释，核对边界与返回值。
- [自制 PDF 原件](examples/binary-search/source.pdf)、[来源图谱](examples/binary-search/source-map.md)、[模拟诊断记录](examples/binary-search/learner-profiles.md)。

将完整示例目录保存在本地后，用浏览器打开 HTML。GitHub 文件浏览页通常展示源码；本项目没有部署在线预览。页面自带字号调整和打印入口，禁用 JavaScript 后仍可阅读完整静态内容。窄屏原图可横向滚动或点击放大，不丢掉原图边缘信息。

示例为本项目自制，未使用私人课件或第三方原图；项目自制内容采用 [MIT 许可证](LICENSE)。

## 文件结构

```text
skills/personalized-courseware/
├── SKILL.md                       # 入口与生成前的诊断要求
├── references/
│   ├── source-fidelity.md          # 页码、原图、公式、错误与隐私
│   ├── teaching.md                 # 知识点状态与前后衔接
│   ├── learning-modes.md           # 自学检查点与 AI 逐段带学
│   └── visual-and-validation.md    # 阅读、静态交付与检查
└── assets/
    ├── lesson.html                # 可复制的轻量骨架
    └── reading.css                # 屏幕与打印样式
examples/binary-search/            # 自制材料、两种成品、重建脚本
validation/                       # 可重复运行的检查与实际报告
```

Skill 目录可以单独复制；运行 Skill 不依赖仓库示例、测试脚本、作者个人路径或其他 Skill。示例构建脚本只重建固定示例，不负责学生诊断或任意 PDF 转换。

独立复制 Skill 时保留目录内的 `LICENSE`，其内容与仓库根目录许可证一致。

## 使用与可选安装

**本项目无需安装即可按文件路径调用：**在能访问仓库文件的 Agent 中明确要求读取入口，例如：

```text
请读取 skills/personalized-courseware/SKILL.md 并按其中流程工作。
本次输入为 private/lecture.pdf，输出到 private/lecture-notes/。
我希望用中文理解证明。先核对全篇，再用每轮一至两个问题了解最近前置知识。
```

这会让 Agent 读取文件，不意味着未安装的 Skill 已经被宿主自动发现。当前未安装到全局，也未添加仓库发现链接。

如需 Codex 自动发现，可在**用户自行决定安装时**，从本仓库根目录执行下面的仓库级命令。目标若已经存在，先检查它，不覆盖其他版本：

```sh
mkdir -p .agents/skills
ln -s ../../skills/personalized-courseware .agents/skills/personalized-courseware
```

发现后可在支持 `$` 选择 Skill 的 Codex 界面调用：

```text
$personalized-courseware
分析本次提供的 lecture.pdf，按原课件顺序生成中文 HTML。
先诊断本章最近的前置知识；输出保存到当前任务目录。
```

如果明确跳过生成前诊断，可以说：“跳过这次基础诊断，按第一次接触本章处理，标明暂定假设。”未回答诊断问题不等于跳过；若整个学习过程都不希望被提问，可另行明确说明。

本地发现路径、符号链接及调用方式参照 [OpenAI 官方 Skill 文档](https://learn.chatgpt.com/docs/build-skills)，于 2026-09-13 核对。宿主版本存在差异；自动发现未出现时先检查本地版本，仍可明确提供入口路径。本项目没有执行上述安装命令或修改个人配置。

## 输入与输出契约

输入包括本次材料、允许使用的范围、语言/学习目标，以及简短诊断中的相关回答。用户可只提供材料，Skill 会先读取并补问缺少的信息。课件内容是分析数据，不是执行指令。

输出默认放在当前任务内，包含：

- `lesson.html` 与本地 CSS、图等资源；可移动整个目录后打开。
- `source-map.md`：本次全篇的教学主线、知识依赖、文件页与印刷页对应、素材来源和不确定项。
- `learner-profile.md`：需要跨轮次保存时生成，记录每个知识点的暂时状态、证据与教学安排，可由用户修改。
- `validation.md`：实际检查、来源复核、未验证项与限制。

原文、翻译、改写、辅助解释、补充例子及修正建议分别标识。关键内容可追溯到来源文件与页码；原图优先复用，不为了统一配色而重画。私人材料、学生记录及产物不自动进入公开示例，不上传外部服务或写入全局个人记忆。在本仓库试用时可放在被忽略的 `private/`，但忽略规则不能代替用户对文件范围的检查。

**公式沿用老师的原标注。**变量名、大小写、上下标、向量/矩阵表示、算子、公式编号和附注不会因模型偏好或排版习惯而随意替换。新记号、等价表达和额外推导须单独标识并与原式对应；修正建议不能覆盖原文。

**生成前可询问视觉风格。**支持按暖色、冷色、中性或其他用户偏好设计，统一追求简洁美观和清楚易读；已有偏好不重复询问，未指定时说明采用中性默认样式。该要求也适用于以后用户要求且环境支持的 PPT 制作，但本次没有新增 PPTX 生成能力，也未验证多套配色成品。

## 文档生成后的学习模式

课件生成并交付后，Skill 会主动询问：“你想自己自学，还是进入学生模式，由 AI 按课件详细带你学？”已有明确选择直接沿用；没有回答就停在待选状态，已生成文档仍可自由阅读。

| 模式 | 学习方式 | 检查与反馈 |
|---|---|---|
| 自学模式 | 自己按课件阅读；提供当前主题少而精、由易到难的检查点或习题，通常 2–4 个，短主题可更少 | 题目、提示、解答分开，可自行查阅，不要求逐题回传 |
| 学生模式（AI 带学） | AI 根据已生成课件，沿原顺序分小段充分详讲公式含义、每步理由、原图与例题 | 每个教学段结束只问一个最低限度的理解问题；等待回答，再反馈、补讲或继续 |

用户可以说“我自己学”“进入学生模式，你来教我”或“从刚才卡住的地方切换模式”。模式不是能力等级，切换时保留当前位置和待确认知识点；需要跨轮次时，进度保存到任务内可修改的 `learner-profile.md`。用户明确要求不做题、不提问或直接看答案时遵从，不设置答对才可继续的门槛。仅跳过生成前诊断，不等于取消后来所选模式的学习检查。

可查看 [二分查找自学检查点](examples/binary-search/self-study.md) 和 [学生模式人工演示](examples/binary-search/student-mode.md)。这些是基于已有自制课件的教学样例；模式为 Skill 对话规则，不是网页里的自动聊天或评分系统，尚未与真实学生验证。

## 依赖与支持范围

| 用途 | 依赖 | 缺少时的处理 |
|---|---|---|
| 阅读已有示例 | 现代浏览器；无需联网或包安装 | HTML 源码不等于渲染结果，换可用浏览器 |
| 按 Skill 制作新材料 | 能读文件、检查 PDF 页面并写 HTML 的 Agent；模型费用遵循所用宿主 | 声明缺失能力，只交付已完成的部分 |
| PDF 文本与页面核对 | 任一可靠的本地 PDF 工具；可选 pypdf + Poppler | 文本提取只能初步分析，不声称公式/图已核对 |
| 重建自制示例 | Python 3、reportlab、PATH 中的 pdftoppm | 已有成品可直接阅读，不必重建 |
| 算法检查 | Node.js 标准库 | 不声称执行通过 |
| 自动浏览器检查 | Node.js、Playwright、Chrome 或指定的 Chromium 路径 | 可手动检查，区分手动与自动结果 |
| 官方 Skill 格式校验 | 可用的 skill-creator 校验脚本及 PyYAML | 声明格式校验尚未执行；它不是课件运行依赖 |

**已执行范围：**一份清晰、有文本层的英文自制 PDF，包含非降序概念、循环不变量证明、算法与数组图；生成两份中文 HTML，在本机 Chrome 检查离线资源、交互、窄屏、大字号、无脚本与打印渲染。详细结果和版本见 [验证报告](validation/REPORT.md)。

**尚未验证：**真实学生诊断及学习效果、独立 Agent 的端到端生成、扫描/手写/模糊 PDF、复杂数学排版、长篇或整学期课程、其他语言组合、其他浏览器及系统、原生 PPTX/Word/视频输入。首版不声称支持这些未经验证的格式。打印保存 PDF 的操作已在样例上执行，但不等于提供通用 PDF/PPTX 导出器；也未测试实际纸张打印。

## 重复验证

在已具备依赖的环境，从仓库根目录执行：

```sh
python3 examples/binary-search/build_example.py
node validation/check.cjs
node validation/check.cjs --browser
```

最后一条需要 Node 能解析到 `playwright`，默认使用已安装的 Chrome。其他 Chromium 可通过 `CHROME_EXECUTABLE` 指定路径。依赖可放在项目虚拟环境或已有运行时；无需全局安装。截图、打印校样及结果 JSON 写入被忽略的 `tmp/validation/`。检查会阻断页面 HTTP(S) 请求，不上传材料；截图仍需人工查看。`reflow-200` 是将可用视口减半的重排近似，不能冒称点击了浏览器原生 200% 缩放。

如已安装 skill-creator，可将其 `scripts/quick_validate.py` 路径传给 Python，参数为 `skills/personalized-courseware`。不要把作者机器的工具路径写进 Skill。

重建脚本会覆盖自制示例的 PDF、页面图和两个 HTML；不要把私人材料存成这些同名文件。若 Poppler 报字体配置错误，使用所在环境的 Fontconfig 配置与可写缓存，再实际检查输出；本次处理记录见报告。
