# 生成课件后的两种学习模式

本参考用于文档交付后的学习支持；不替代生成前诊断，也不改变原课件顺序、公式标注与来源要求。

## 模式选择与继续学习

生成并交付教学文档后，主动询问用户选择：

- **自学模式**：自己阅读课件，配少量从简单到难的检查点或习题，可自行查提示与解答。
- **学生模式（AI 带学）**：AI 依据生成课件逐段详细讲解，每段后只问一个必要的理解检查问题，根据回答调整。

这不是基础高低的分类；任何基础都可选择任何模式。用户事先已经说“我要自学”或“你来教我”时，交付后承接该选择即可。用户没有回答时不要自行选模式；文档已经交付，仍可自由阅读。用户只要文档或明确不继续学习时不反复邀请。

继续已有课件时先核对当前文档版本、来源图谱和已记录进度；用户直接指定某节时核对该位置，再从那里继续。无权访问的文件不能假装读过，生成课件有疑点时回看已提供的原页，不能把生成稿当作新的权威来源。

跨轮次需要保存时，在任务内 `learner-profile.md` 追加：所选模式、当前课件版本与节/锚点、最近实际讲过或用户报告读过的内容、待答问题/检查点、用户回答与暂时判断、建议下一步。只记录实际证据；生成了某节、展示了答案或发送了讲解，都不等于学生掌握。自学进度未报告时保持未知。用户可查看、修改或清除这些记录，不写入全局个人记忆。

切换模式时保留材料与位置，不重做整份课件或重考已确认的基础。自学转带学可从卡住的检查点展开；带学转自学可交付剩余部分的简短阅读路线和检查点。未完成的判断保留不确定，不为切换强制补答。

## 自学模式：少而精、由易到难

按当前小节或紧凑主题选题，而非每页配题或一开始生成整门课程题库。通常 2–4 个检查点就够；短小主题可只用 1 个，不为满足数量重复出题。难度从含义/识图出发，再到单步应用，最后按材料范围选择推理、条件辨析或小迁移；不要突然要求未学的后续章节。

每题都要有明确目的，能检查一个关键理解或常见误区，并给出课件位置与对应原页。依据学生基础调整起点：已能解释概念则减少辨认题，应用薄弱则保留一步推演，推导薄弱则检查理由。新增题标“新增自学检查”；引用老师原题则保留原题与来源。

在任务输出目录提供可独立阅读的检查点文档，或经核对后追加到课件相应位置。格式可以沿用当前可用的 HTML/Markdown，不为几道题引入评分后台。题目、提示、参考解答分开；默认先呈现题目，提示与答案放后部或独立区域，不紧跟题干直接泄露结论。若采用折叠，保证无脚本可用，并核对打印时完整呈现。静态文档可用分开的题目区和答案区。

参考解答说明关键理由和适用条件，可列“做到什么就算检查到位”，不只给数值。保留老师记号，验证新增题解和数值，不编造老师意图。习题难度增加不能靠堆计算量；不为完整性添加大批同型题。

交付后由学生自行阅读和作答，不要求逐题回传、定时打卡或答对解锁。学生回来提问时，定位对应知识点提供提示或解释；要答案就给答案，不强制先作答。没有反馈时不宣称检查点已通过。

## 学生模式：最充分的解释，小段推进

以已生成课件的路线为主线，按学生知识起点尽可能详细地解释当前小段，不省略关键步骤；“详细”不是一次倾倒整章，也不是反复扩展无关基础。每次选择一个可连贯完成的小目标，例如读懂一个定义、证明一个局部结论或完成一次算法更新。

讲解时按内容自然组织以下信息，不必机械套标题：

1. 指明课件位置、当前问题，以及它与上一段和本章目标的关系。
2. 先给目标语言的直觉，再沿老师原符号解释公式中各量、条件和含义。已确实掌握的前置知识可简短提醒；薄弱处展开，必要补充后返回主线。
3. 定义用原图或原例说明；证明解释每步依据、所用条件及它对最终目标的作用；算法解释比较前状态、分支理由、更新后状态和边界。复杂步骤拆细，不能用“显然/容易得到”跳过学生尚未理解的推导。
4. 必要时提供一个有标识的补充例子、反例或视觉说明，核对数学与来源；不改变原例或原标注。
5. 用一两句话回扣本段结论，然后提出**恰好一个最低限度的理解检查问题**。

检查只覆盖刚讲过的一个关键点，可用一句解释、一次判断并给最短理由、一次索引更新或指出图中一个关系。不能把数个子问题塞进“一题”，不问笼统的“懂了吗”，也不借检查引入下一节的难点。以该问题结束本次教学段，等待回答；同一轮不提前给出检查答案，不继续讲下一个依赖它的段落。

收到回答后：

- **回答到位**：指出关键理由为什么成立，更新相应知识点的暂时证据，再进入下一小段。每个新教学段仍以一个最低检查结束。
- **部分理解或答错**：指出具体一步的偏差，用更小的解释或原图/原例补讲，然后只问一个更小的检查；不要一面补讲一面又推进新主题。
- **说不会或要求提示**：给最小必要提示；需要补讲时详细解释当前缺口，再用一个更小问题检查，不追加一串练习。
- **要求答案、跳过或停止提问**：遵从，必要时直接讲解答案；没有独立回答的知识点仍保留未确认。不能要求答对才允许继续。
- **没有回答**：停在待答状态，不模拟学生答案、不自动推进、不重复催问。

若一个缺口反复卡住，缩小目标或换一种已核对的解释，再询问是否继续细讲或先向前看；不要无止境加题。用户可以随时调整节奏、切回自学或要求无检查讲解。

## 模式验证

用同一份已生成课件检查以下可观察行为，区分人工模拟、独立 Agent 实际执行与真实学生反馈：

- 完成文档后才询问学习模式；已选、仅要文档、未回答三种情形处理正确。
- 自学检查点数量克制、由易到难且不超范围；题目来源、解答理由与原记号可核对；题目与答案分离，没有强制回传。
- 学生模式详讲一个小段，末尾只留一个实际能检查理解的问题；没有同轮泄露答案或越过待答问题。
- 正确、部分正确、错误、求提示、跳过、无回答时，下一步确实不同；记录只反映已发生的证据。
- 两种模式切换保留当前页和未确认项，不重置课程或替换原文。未真实与学生执行时，不声称这些规则已证明教学效果。
