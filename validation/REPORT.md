# 首版验证报告

日期：2026-09-13。对象：本地 `skills/personalized-courseware/` 与自制 `examples/binary-search/`。此报告记录首版验证及后续规则增补，不代表真实学生实验，也不代表独立 Agent 完成了端到端诊断和生成。仓库的提交与可见性是后续发布操作，不改变这些教学验证结论。

## 补充规则的验证范围

按后续用户要求，强化了公式原标注保护，并加入生成前可询问暖色、冷色或其他风格偏好的规则。人工检查确认：新等价表达不能替换原式、默认配色不改老师标注、未答风格问题不阻塞生成且不代表知识诊断完成；PPT 的制作要求与当前已验证格式仍明确区分。本次仅修改 Skill 与说明文档，格式及相对参考链接已重新检查。以下成品检查来自首版既有示例；未重新生成不同配色示例或 PPT，也未新增真实用户风格选择或复杂公式标注保留的执行验证。

## 两种学习模式的增补验证

新增 `references/learning-modes.md`，并同步主入口、教学与验证规则、README。消除了“练习只有额外要求才增加”与模式默认行为的歧义：选择自学即提供少量递进检查，选择学生模式即逐段详讲并每段一个最低检查，仍尊重跳过或不提问的明确要求。

- **实际编写**：[self-study.md](../examples/binary-search/self-study.md) 含 3 个由闭区间含义、单步更新到前提反例的检查点，提示与解答分区；[student-mode.md](../examples/binary-search/student-mode.md) 展示一段详细教学、一个检查问题，以及正确、错误、求提示、跳过、无回答、切换模式的后续处理。
- **实际执行检查**：Skill 官方格式校验与本地文档引用解析重新通过；用一次性 Python 断言核对自学题的计数、原例更新与无序反例，以及带学检查的索引数量。未修改原 HTML、CSS、PDF 或交互代码，因此未重复原有浏览器回归；下面的 HTML 检查仍对应首版成品。
- **人工走读**：核对模式询问发生在文档交付后、带学先讲一个小目标并在单题后停下、答案只出现在后续反馈分支、自学答案与题目分开；没有答案不推进，没有反馈不写成掌握。
- **尚未验证**：本次没有真实学生回答，也未运行独立 Agent 多轮教学、自动进度恢复或学习效果实验。Markdown 演示描述的分支不是已经发生的用户对话，不能据此声称模式行为已获得完整端到端验证。

## 实际渲染发现与修正

1. CSS 中 flex 显示规则覆盖了 HTML 的 `hidden`：首次无脚本检查失败。补上明确的 `[hidden]` 规则，再运行两版验证通过。
2. 手机宽度将整页原图缩得过小：查看实际截图后，改为保持原图最小可读宽度，配有说明、可聚焦的滚动区域和原图链接。正文与关键转录仍自动换行。测试核对可滚至右边缘，不以隐藏裁切代替完整原图。
3. 小屏状态表的更新列过窄：调整为候选区间 28%、中点 12%、值 16%、理由 44%，复查重排与截图。
4. 第一轮打印将完整算法拆到两页：增加短代码块防拆页规则，最终校样中两版的算法均完整排在同一页。打印隐藏当前交互快照，所有关键静态轨迹仍保留。
5. 原始 Poppler 环境的字体配置指向不可写缓存：第一次虽然产生了可读图片，但出现大量字体警告。使用任务内临时 Fontconfig 配置与可写缓存重新渲染，最终渲染日志为空。该机器适配未写进可移植 Skill。

最后查看了三张完整源页、两版桌面截图及手机/大字号/重排的代表区域，并渲染全部打印页，检查布局总览与算法、证明、表格等关键页。已查看区域未发现遮挡、公式截断或正文拥挤。打印为了保留整页原图和完整代码块，部分页面有较多留白；这是当前静态排版的已知取舍，未声称专业出版级分页。
