# Project conventions

- Use tabs for code indentation. For formats that forbid tabs, avoid nested syntax or follow that format's required syntax.
- Keep the portable skill in `skills/personalized-courseware/`.
- Preserve source evidence, teaching order, and conditions. Label added teaching content.
- Use only self-authored or explicitly redistributable material in examples. Keep user courseware and learner records in the current task's private directory, never in examples.
- Do not commit, push, publish, install globally, or choose a license unless explicitly requested.
- Report automated checks, manual simulations, visual inspection, and real learner evaluation separately.
